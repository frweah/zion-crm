# Design mock-ups

The screens the owner drew before they were built. One file per screen,
named for the screen: `client-dashboard.png`, and later `billing-board.png`
and `clients-board.png` when those arrive.

**A mock-up with a real client on it does not come in here.** The client
dashboard mock uses invented people - the name, the family contact, the
authorization numbers and the invoice number on it match nothing in the
database, checked before it was committed. The staff first names on it are
real and already appear throughout `BUILD-LOG.md`.

There is a PNG of the old Notion "Client Master Board" in the brief folder
outside the repository. It carries sixteen real clients with dates of birth
and home addresses. It stays out.
