# Timing — My work hub, before

Five named tasks each, on a phone, before anything in My work changes. The
same five are timed again after the hub is changed; if the after times are
worse, the hub is rolled back (brief, Part 2 step 4).

**How to time one.** Start on Home, signed in, phone unlocked. Start the
stopwatch on the first tap; stop it when the screen says it is saved (or, for
a look-up, when the answer is on screen). One practice run first, then the
timed run. Write down anything that made you stop and look.

Use a test client where a task writes something: **ZZ Smoke Board**.
